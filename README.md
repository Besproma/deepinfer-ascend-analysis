# DeepInfer 昇腾适配与计算架构分析

本目录是 `DeepInfer 昇腾适配与计算架构分析` 的独立发布版本，不修改 DeepInfer 官方仓库。

## 内容

- `docs/index.html`：完整交互版报告，适合通过 GitHub Pages 发布。
- `docs/assets/`：CSDN 图文版使用的配图。
- `csdn/article.md`：CSDN Markdown 正文。
- `csdn/images/`：Markdown 本地预览所需图片。

## GitHub Pages

仓库发布设置选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/docs`

发布后的入口为：

```text
https://besproma.github.io/deepinfer-ascend-analysis/
```
